# 수강생 사용 안내

[2쪽 퀵가이드 PDF](manual/AssignmentHub_퀵가이드.pdf)에서 수강생용 절차를 먼저 확인할 수 있습니다. 상세 화면과 상황별 예시는 [시나리오별 매뉴얼](manual/scenarios.md)을 참고하세요.

## 첫 로그인

관리자가 안내한 서버 주소를 Chrome 또는 Edge에서 엽니다. ID와 배포받은 임시비밀번호를 입력합니다. 최초 로그인 또는 비밀번호 초기화 상태에서는 먼저 새 비밀번호를 두 번 입력해야 합니다. 비밀번호는 12~128자이며 현재·임시비밀번호와 달라야 합니다. 붙여넣기를 사용할 수 있습니다.

변경이 끝나면 **새 비밀번호로 다시 로그인**합니다. 변경 전에는 과제 조회·업로드·다운로드를 사용할 수 없습니다. ID는 대소문자를 구분하고 앞자리 0을 포함하므로 안내받은 그대로 입력하세요.

## 과제 파일 제출

1. 접수 중인 과제를 선택하고 설명을 확인합니다.
2. 브라우저 업로드 화면을 엽니다. 화면의 연결 코드를 복사·입력하거나 같은 ID/비밀번호로 로그인합니다. 연결 코드는 짧은 시간 동안 한 번만 사용할 수 있습니다.
3. 이번 제출에 포함할 파일들을 선택하거나 PC에서 파일 선택 영역으로 끌어 놓습니다. **선택만으로 전송되지 않습니다.** 파일명, 각 크기, 합계, 사용 중인 용량과 제한을 확인합니다.
4. 제출 시작을 누릅니다. 파일 무결성 확인 후 청크 전송을 시작합니다. 기본 파일당 2GiB, 한 제출 최대 10개, 내 누적 보존 용량 10GiB입니다.
5. 현재 파일·순번, 파일별/전체 수신량과 진행률, 대기·전송·재시도·검증·저장 상태를 확인합니다.
6. 모든 파일 검증과 서버 저장이 끝난 **제출 완료** 화면에서 제출번호, 과제, ID, 원본 이름, 크기, 서버 완료 시각을 확인합니다. 전송 100%만으로 제출 완료가 아닙니다.

여러 파일은 한 묶음입니다. 일부 파일만 전송되면 완료 제출자로 집계되지 않습니다. 선택한 파일을 모두 끝내거나 묶음을 취소하고 새로 시작하세요. 재제출하면 새 제출번호와 버전이 만들어지고 이전 완료 제출은 보존됩니다.

## 연결 끊김·새로고침·재시도

잠시 연결이 끊어지면 제한된 횟수만 자동 재시도합니다. 계속 실패하면 사유를 확인하고 수동 재시도를 누릅니다. 서버가 확정한 전송량부터 이어 올리므로 표시한 전체 파일을 처음부터 무조건 다시 전송하지 않습니다.

새로고침·브라우저 종료·서버 재시작 후에는 다시 로그인하고 미완료 작업을 선택합니다. 브라우저가 파일 접근을 잊은 경우 **처음 선택했던 동일 파일**을 다시 선택하세요. 이름·크기뿐 아니라 SHA-256도 확인하므로 내용이 바뀐 파일을 이어 붙일 수 없습니다. 파일을 수정했다면 기존 미완료 작업을 취소하고 새 제출을 시작합니다.

기본 보관 시간은 마지막 활동 후 24시간입니다. 그 시간이 지나거나 취소하면 미완료 파일과 예약 용량을 정리합니다. 계정이 초기화·비활성화되거나 세션이 만료되면 기존 권한으로 계속 전송할 수 없습니다. 관리자 안내에 따라 비밀번호 변경·재로그인을 마친 뒤 작업 상태를 확인합니다.

## 용량과 제출 확인

창이 좁으면 저장 용량과 이어 올리기 영역이 파일 선택 아래로 이동합니다. 아래로 스크롤해 확인하세요. 관리자·수강생 화면의 메뉴가 접혀 있으면 왼쪽 위 메뉴 열기 버튼으로 펼칩니다. 표는 표 안에서 가로로 스크롤하고, 긴 파일명은 줄바꿈으로 확인할 수 있습니다. [실제 작은 화면 예시](manual/screenshots/23-upload-mobile.png)

`GiB`는 1,073,741,824바이트이며 화면의 바이트 수가 기준입니다. 이전 과제·이전 제출 버전도 내 사용량에 포함합니다. 진행 중인 다른 탭의 제출은 예약 용량으로 포함합니다. 한도 또는 서버 디스크 여유가 부족하다는 안내가 나오면 미완료 작업을 취소하거나 관리자에게 문의하세요.

제출 이력에서 최신 완료 제출과 이전 완료 제출을 확인하고 내 파일을 다운로드할 수 있습니다. 실패한 새 제출이 이전 완료 제출을 지우지 않습니다. 완료 시각은 서버 기준이며 기본 표시 시간대는 Asia/Seoul입니다. 본인 외 사용자의 제출물을 조회할 수 없습니다. 사용을 마치면 로그아웃하세요.
