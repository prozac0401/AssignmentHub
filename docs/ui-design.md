# UI 디자인과 화면 크기 대응

2026년 9월 디자인 개편은 Windows 서버 관리창, Streamlit 수업 화면, 브라우저 파일 제출 화면을 함께 다룹니다. 외부 폰트나 아이콘 CDN 없이 오프라인 교육장에서도 같은 디자인을 사용합니다.

## 참고한 제품과 기준

- [Linear UI 개편](https://linear.app/now/how-we-redesigned-the-linear-ui): 메뉴 정렬, 정보의 우선순위, 여백을 참고했습니다.
- [Microsoft Fluent 2 레이아웃](https://fluent2.microsoft.design/layout): 창 크기에 따른 재배치와 일관된 간격을 참고했습니다.

브랜드 자산을 복제하지 않고 AssignmentHub의 실제 기능과 한국어 설명에 적용했습니다. 배경 `#F7F8FC`, 본문 `#202539`, 보조 설명 `#647087`, 주요 동작 `#4F46E5`를 사용합니다. 성공과 오류 상태는 색상과 문구로 함께 구분합니다.

## 화면별 동작

| 화면 | 넓은 창 | 좁은 창 |
| --- | --- | --- |
| 서버 관리 | 과정 표, 한 줄 실행 버튼 | 버튼을 두 줄로 재배치, 내용 세로 스크롤 |
| 과정 설정 | 기본 정보와 용량 설정 탭 | 입력 영역 스크롤, Tab 이동 시 입력란 표시 |
| 로그인 | 안내와 로그인 폼을 나란히 표시 | 폼을 안내 아래에 표시 |
| 관리자·수강생 | 메뉴와 본문, 여러 열의 수치 | 메뉴 접기, 수치와 입력 영역 재배치, 표 내부 스크롤 |
| 파일 제출 | 파일 선택과 저장 용량을 나란히 표시 | 760px 이하에서 한 열로 배치, 긴 파일명 줄바꿈 |

키보드 포커스 표시, 본문 바로가기, 전송률의 접근성 이름, 동작 감소 설정을 지원합니다. 파일 선택 영역의 드래그 앤 드롭은 파일 선택 버튼과 동일한 검증·전송 흐름을 사용하며 전송 중에는 선택을 바꿀 수 없습니다.

과정 설정 탭은 선택·비선택 상태에서 같은 높이와 여백을 유지합니다. 선택한 탭에 연보라색 배경과 진한 글자색을 적용하고 테두리는 평평하게 통일했습니다. 기본 테마가 선택 탭에만 적용하던 여백 설정을 제거하여 새 과정과 기존 과정 설정에 함께 반영했습니다.

## 재현 자료

[화면 매뉴얼](manual/README.md)에 실제 창과 브라우저 캡처를 보관합니다. `scripts/capture_manual.py`는 격리된 예시 과정을 생성하고, `scripts/capture_manual.cjs`는 실제 서버로 제출·이어 올리기·다운로드를 수행합니다. 로그인, 긴 파일명이 있는 제출 화면, 관리자 현황을 360/390/600/768/1024/1440px 폭에서 확인합니다. 결과는 [walkthrough.json](manual/walkthrough.json)에 기록합니다.

`tests/test_desktop_layout.py`는 창을 줄였다가 다시 늘릴 때 내용 높이, 버튼 접근성, 작은 설정 창의 키보드 이동을 확인합니다. 실제 스마트폰·터치 입력·다른 PC의 네트워크 접속은 브라우저 뷰포트 검사와 별개입니다.
