# 화면 설명 작성 기준

서버 화면은 계정, 과제, 제출 상태와 사용 절차를 설명합니다.

- 슬로건, 홍보성 수식어, 성과·편의성을 보장하는 표현을 사용하지 않습니다.
- 기능 설명은 현재 코드가 제공하는 동작과 설정값에 근거합니다.
- 상태·인원·파일 수·용량은 서버 응답으로 표시하고 집계 범위를 함께 밝힙니다.
- 검사 결과는 검사한 범위만 설명합니다. 영상 첫 5초 검사 통과를 전체 영상의 품질이나 내용이 적절하다는 뜻으로 표현하지 않습니다.
- 과제 안내에는 실제 제출할 산출물, 제출 방법, 기한 등 운영자가 확인한 정보를 입력합니다.
- 사용자가 판단하거나 조치하는 데 필요하지 않은 내부 구현 용어는 화면에서 줄이고 기술 문서에 설명합니다.

적용 위치: 로그인 안내, 운영 안내, 과제 관리, 제출 현황, 파일 업로드 및 영상 검사 결과.
