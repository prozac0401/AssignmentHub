# AssignmentHub v1.3.0 퀵가이드

[인쇄용 2쪽 PDF](AssignmentHub_퀵가이드.pdf) · [시나리오별 상세 매뉴얼](scenarios.md)

## 1쪽: 운영자용

1. **압축 해제와 실행**: `AssignmentHub-1.3.0-windows-x64.zip` 전체를 쓰기 가능한 폴더에 풀고 `start.bat`를 실행합니다. Python·라이브러리 설치는 필요 없습니다.
2. **새 과정 만들기**: 과정명, 실제 교육장 네트워크 IP, 관리자 ID와 8~128자 비밀번호를 정합니다. 과정 ID·포트·저장 폴더를 확인합니다.
3. **서버 시작**: 과정을 선택하고 `서버 시작`을 누릅니다. 실행 중을 확인한 뒤 `관리자 화면 열기`로 로그인합니다. `주소 복사`로 학생에게 URL을 안내합니다.
4. **TSV 명단 등록**: 사용자 관리에서 아래 내용을 탭으로 구분해 붙여넣거나 `.tsv`/`.txt` 파일을 올립니다. `명단 검증 및 미리보기`로 확인하고 `검증된 명단 반영`을 누릅니다.

```tsv
user_id	name	group
001	홍길동	A반
002	김민수	B반
```

`user_id`, `name`은 필수, `group`은 선택입니다. `001`의 앞자리 0을 유지하세요. 임시비밀번호는 영문·숫자 8자리입니다. 반영 전 공통 임시비밀번호 옵션을 켜면 신규 계정에 같은 값을 지정할 수 있습니다. 추가 등록 때도 같은 값을 입력하세요.

5. **계정 전달**: 등록 직후 임시비밀번호 결과 CSV를 내려받아 학생별로 전달하고 결과를 닫습니다. 비밀번호 분실 시 사용자 관리에서 해당 학생만 초기화합니다.
6. **과제 접수**: 과제 관리에서 제목·설명을 입력하고 접수를 시작합니다. 학생에게 정확한 과제명을 안내합니다.
7. **제출 확인**: 제출 현황에서 과제를 선택해 제출자·미제출자를 확인합니다. 필요하면 전체 현황 CSV와 원하는 제출 버전의 파일을 다운로드합니다.
8. **종료와 백업**: 과제 접수를 닫고 진행 작업을 확인합니다. `서버 중지` 후 중지 상태를 확인하고, 설정 JSON과 저장 폴더 전체를 같은 시점으로 백업합니다.

**접속 문제:** `127.0.0.1`은 다른 PC용 주소가 아닙니다. 실제 서버 IP·포트, 교육장 네트워크와 방화벽을 확인하고 `접속·오류 점검`을 실행하세요.

**중지 주의:** 관리창을 닫아도 서버는 유지됩니다. 접수 종료는 신규 제출만 막고, 기존 유효 업로드는 완료할 수 있습니다.

## 2쪽: 수강생용

1. **로그인**: 운영자가 안내한 주소를 열고 본인 ID와 임시비밀번호로 로그인합니다. `001`의 0과 대소문자를 그대로 입력합니다.
2. **첫 비밀번호 변경**: 현재 임시비밀번호와 새 8~128자 비밀번호를 입력하고 변경합니다. 새 비밀번호로 다시 로그인합니다.
3. **바로 제출하기**: 과제를 선택하고 `파일 제출·이어 올리기`를 누릅니다. 현재 계정과 선택한 과제로 제출 창이 바로 열립니다.
4. **과제와 파일 선택**: 안내받은 과제를 고르고 이번 제출에 필요한 파일을 모두 선택합니다. 파일명·개수·용량을 확인합니다. 파일 선택만으로 전송되지 않습니다.
5. **제출 시작과 완료**: `제출 시작`을 누릅니다. 전송률 100% 이후에도 기다리고, `제출이 완료되었습니다`와 **제출번호**를 확인합니다. 이력에서 파일을 다시 내려받을 수 있습니다.
6. **중단 후 이어 올리기**: 제출 창을 다시 열고 미완료 작업의 `이 작업 이어 올리기`를 선택합니다. 처음의 동일 원본 파일을 모두 고른 뒤 `확인 후 이어 올리기`를 누릅니다.
7. **수정본 재제출**: 완료한 파일을 수정했다면 `다른 파일 새로 제출`로 같은 과제에 다시 제출합니다. 새 제출번호와 버전이 생기며 이전 완료 파일은 유지됩니다.
8. **사용 종료**: 제출번호와 파일 목록을 확인하고 로그아웃합니다. 문제가 있으면 과정명·ID·제출번호·오류 문구를 운영자에게 알려 주세요.

**기본 한도:** 파일당 2 GiB / 한 제출 최대 10개 / 학생별 누적 10 GiB. 수업 설정에 따라 다르며, 이전 과제와 버전도 누적 용량에 포함됩니다.

**원본 유지:** 이어 올릴 파일은 이름·크기·내용이 같아야 합니다. 내용을 바꿨으면 미완료 작업을 취소하고 새로 제출하세요. 기본 미완료 보관 시간은 마지막 활동 후 24시간입니다.

**완료 기준:** 파일 묶음이 모두 끝나야 완료 제출입니다. 진행률만 보고 창을 닫지 말고 제출번호를 확인하세요.
