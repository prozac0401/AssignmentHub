# AssignmentHub v1.2.0 사용 매뉴얼

**무설치 실행과 TSV 명단 입력**에 맞춰 2026-09-08에 개정했습니다. 처음 수업을 준비하는 운영자와 과제를 제출하는 수강생이 각각 필요한 절차를 찾을 수 있습니다.

매뉴얼 ZIP 전체를 별도 폴더에 풀고 `index.html`을 열면 화면과 예시를 인터넷 없이 볼 수 있습니다. PDF와 PPTX도 같은 폴더에 포함됩니다. 현재 릴리즈에서는 이 개정본을 별도 첨부 파일로 제공합니다.

## TSV 예시 파일

- [첫 명단 등록](examples/01-first-roster.tsv): `001` 홍길동 A반, `002` 김민수 B반을 등록합니다.
- [추가 등록과 그룹 변경](examples/02-add-and-update.tsv): `002`를 A반으로 바꾸고 `003` 이서연을 B반에 추가합니다.
- [중복 오류 확인](examples/03-duplicate-error.tsv): 의도적으로 ID `001`을 중복 입력한 예시입니다. 오류 확인 후 고쳐 사용합니다.

`user_id`, `name`은 필수이며 `group`은 선택입니다. 탭으로 구분하고 앞자리 0을 유지합니다. 명단 입력은 TSV이고 임시비밀번호·현황 내보내기는 CSV입니다.

## 예시 화면을 볼 때

파이썬 기초 실습과 데이터 분석 오후반은 가상 과정입니다. 캡처의 `127.0.0.1`, 임의 포트와 `.local-tests` 경로는 재현용이며, 실제 교육장에서는 서버의 네트워크 IP와 운영용 저장 폴더로 바꿔 사용합니다. 비밀번호 결과를 닫은 뒤 캡처했으며, 입력 비밀번호와 일회용 연결 코드는 가렸습니다.

이어 올리기는 처음의 원본 두 파일을 그대로 사용한 예시입니다. 수정본 재제출은 새 제출번호와 버전이 생기는 별도 작업으로 설명합니다. 백업·복원은 운영 절차 예시이며 다른 물리 PC에서의 복원 훈련을 수행했다는 의미는 아닙니다.

## 유지보수

- `slides.json`, `routes.json`, `scenarios.json`: 설명 문구, 시나리오 목차와 완료 기준입니다.
- `scripts/capture_manual.py`, `scripts/capture_manual.cjs`: 별도 예시 과정을 만들고 실제 화면을 다시 캡처합니다.
- `scripts/build_manual.mjs`: 편집 가능한 PPTX를 생성합니다.
- `scripts/render_manual_powerpoint.py`: 생성한 PPTX를 PowerPoint에서 읽기 전용으로 렌더링하고 PDF 사본을 내보냅니다.
- `scripts/build_quick_guide.py`, `scripts/build_manual_web.py`: 퀵가이드 PDF와 오프라인 웹 매뉴얼을 만듭니다.

이 도구들의 개발 의존성은 서버 사용자에게 설치할 필요가 없습니다. 실제 명단과 비밀번호, 과정 설정·계정 DB·제출 파일을 Git이나 매뉴얼 ZIP에 넣지 않습니다.
