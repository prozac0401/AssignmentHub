# v1.3.0 비밀번호와 직접 제출 검증

2026-09-08, Windows 11 x64와 실제 Edge 152.0.4191.66에서 확인했습니다. 테스트용 차수·계정·저장 폴더를 별도로 만들었으며 운영 자료를 사용하지 않았습니다.

## 변경 동작

- 관리자 생성과 학생 비밀번호 변경에 8~128자 규칙을 동일하게 적용합니다. 7자는 거절하고 8자와 128자는 허용하며 129자는 거절합니다.
- 최초 등록 및 개별 초기화 임시비밀번호는 영문·숫자 8자리로, UTF-8에서도 정확히 8바이트입니다.
- 명단 반영 전 공통 임시비밀번호를 지정하면 해당 명단의 신규 계정에만 같은 값이 적용됩니다. 기존 비밀번호·제출 기록은 유지되고 추가 등록 때 공통값을 다시 지정합니다. 개인별 해시의 salt는 서로 다릅니다.
- 첫 로그인 후 개인 비밀번호 변경은 유지합니다. 공통값·임시비밀번호를 설정 JSON이나 관리 기록에 평문으로 저장하지 않습니다.
- 수업 화면의 파일 제출 버튼은 현재 로그인과 선택한 과제로 제출 창을 바로 엽니다. 연결 코드 화면과 발급·교환 API는 제거했습니다. 로그인 토큰을 URL·쿠키·브라우저 저장소에 저장하지 않습니다.
