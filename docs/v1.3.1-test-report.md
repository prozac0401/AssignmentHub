# v1.3.1 서버 관리창 진행 표시 검증

2026-09-08, Windows x64 / Python 3.12 / 실제 Tcl/Tk 관리창에서 확인했습니다.

## 수정 내용

자동 상태 확인과 네트워크 주소 조회도 진행 막대를 시작하던 처리를 분리했습니다. 시작·중지·설정 저장 등 운영자가 요청한 작업 중에만 막대와 경과 시간을 표시합니다. 완료 또는 실패 시 애니메이션을 멈추고 값을 초기화한 뒤 막대를 숨깁니다. 막대가 나타나고 사라져도 아래 안내의 위치는 유지합니다.

자동 확인이 완료·오류 안내를 덮어쓰지 않습니다. 동시에 요청한 작업이 여러 개이면 작업 수를 함께 표시하고, 마지막 요청 작업이 끝날 때 진행 표시를 종료합니다. 오류 대화상자나 점검 결과 창을 열기 전에 완료된 작업의 표시를 종료합니다. 상단의 새로고침을 직접 누르면 해당 조회 작업의 진행 상태를 표시합니다.

## 자동 검사

다음 명령으로 **14개 검사 모두 통과**했습니다.

```bat
.venv\Scripts\python.exe -X utf8 -m pytest tests/test_manager_progress.py tests/test_server_manager.py tests/test_manager_entrypoint.py tests/test_launcher.py -q -rs
```

| 범위 | 확인 내용 |
| --- | --- |
| 자동 확인 / 직접 새로고침 | 자동 확인 동안 막대가 숨겨진 채 값 0 유지, 완료 안내 유지, 직접 새로고침은 작업 중 표시 |
| 동시 작업, 두 가지 완료 순서 | 먼저 요청한 작업 또는 나중 요청한 작업이 먼저 끝나는 경우 모두 남은 작업 표시 유지; 대기 중인 자동 조회는 종료 시점에 영향 없음 |
| 실패 / 재시도 | 오류 대화상자의 Tk 이벤트 루프에서도 막대가 정지한 상태 유지, 다음 작업은 초기값에서 다시 시작 |
| 실제 관리창 / 서버 | 과정 생성, 서버 시작·중지 중 표시, 실제 API 응답과 Edge 관리자 화면, 완료 안내, 관리창을 닫고 다시 열어도 서버 유지, 중지 후 설정 변경 |
| BAT / 실행 도구 | 실제 pythonw 관리창 실행, 과정별 프로세스·저장소 잠금과 서버 수명주기 회귀 검사 |

진행 표시 시나리오마다 별도 프로세스에서 실제 Tk 위젯과 작업 스레드를 사용합니다. 대기용 이벤트로 작업 완료 순서를 제어하며 실제 서버 수명주기는 별도 관리창 검사에서 확인합니다. 위젯 콜백 호출을 통한 검사로, OS 마우스 입력 자동화는 포함하지 않습니다.
